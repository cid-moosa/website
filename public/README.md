> Modern, ultra-responsive, standalone web portal for **Girideepam Institute of Advanced Learning (GIAL)**, Kottayam, Kerala. Featuring dynamic CBCS curriculum explorer windows, domain-thematic interactive canvas animation engines, authentic faculty profile directories, and zero external redirects.

---

## 🌟 Key Features

- **Domain-Themed Canvas Particle Engines**:
  - **Cyber Forensics**: Authentic classic ASCII CMatrix digital rain engine with vertical Katakana/ASCII streams, luminous phosphor gradients, and smooth gravitational spacetime absorption.
  - **Psychology & Neuroscience**: Synaptic neural mesh with dynamic neurotransmitter connectors (`Ψ`, `🧠`, `α`, `β`).
  - **BCA & Logic Architecture**: High-speed logic circuit network (`</>`, `AI`, `&&`, `{}`).
  - **Logistics & Supply Chain**: Global maritime & aviation trade routes (`⚓`, `🚢`, `✈️`, `📦`).
  - **BBA & Corporate Leadership**: Dynamic vector analytics and executive growth metrics (`📈`, `▲`, `ROI`, `💼`).
  - **Commerce & Taxation**: Fiscal ledger mathematics and wealth nodes (`₹`, `$`, `€`, `∑`, `∆`).
  - **MSW (Social Work)**: Humanitarian community empathy network (`🤝`, `♥`, `★`, `👥`).
- **Smooth LERP Physics Scroll Engine**: 2-second continuous cinematic scroll translation with camera push-in and seamless docking into the ISO 9001:2015 institutional showcase.
- **Dedicated Program Windows (`program.html`)**: Complete 6-semester CBCS syllabi, lab equipment details, career avenues, and fast-track admission forms for all 10 UG/PG courses.
- **Interactive Faculty Profiles Modal**: High-definition faculty portraits, academic qualifications, research specializations, phone/email contact links, and real-time cipher character scramble decryption reveal animations.
- **Clubs & Associations Showcase**: Full-bleed photo cards with hover-reveal glassmorphic descriptions.
- **Mobile First & Ultra-Fast**: 100% self-contained frontend with custom glassmorphic scrollbars, responsive bottom action bars, and zero bulky third-party frontend framework overhead.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Glassmorphic Design System), Vanilla JavaScript (ES6+), HTML5 2D Canvas Engines
- **Backend / Dev Server**: Node.js, Express.js, Helmet, CORS
- **Typography & Icons**: Google Fonts (Plus Jakarta Sans, Outfit, Space Grotesk, Courier New)

## 💻 Quickstart (Local Development)

```bash
# 1. Clone the repository
git clone https://github.com/cid-moosa/website.git
cd website

# 2. Install dependencies
npm install

# 3. Start local development server
npm start
# -> Server running on http://localhost:3000
```
